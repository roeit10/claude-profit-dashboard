# דשבורד רווחיות ותזרים — Claude Code Skill

Skill ל-Claude Code שבונה דשבורד חודשי לעסק: כמה נכנס, כמה יצא, כמה נשאר —
ולאן הכסף הולך. קובץ HTML אחד שנפתח בדפדפן, נבנה מהנתונים האמיתיים שלכם.

**ההמשך הטבעי של סקיל הקבלות** ([claude-receipts-to-accountant](https://github.com/roeit10/claude-receipts-to-accountant)):
הגיליון שהוא בונה כל חודש הופך כאן למקור הנתונים. מי שאין לו — הסקיל מקים
גיליון ידני פשוט באותו מבנה.

---

## מה מקבלים

- **שורת מצב** — החודש האחרון: הכנסות, הוצאות, כמה נשאר, ושינוי מול החודש הקודם.
- **גרף 6 חודשים** — הכנסות מול הוצאות + קו הרווח.
- **לאן הכסף הולך** — פילוח לפי קטגוריות, עם סימון אדום לקטגוריה שחרגה.
- **שלוש תובנות** — מהנתונים בלבד, כל אחת עם המספרים שמאחוריה.
- **קופסת "מה חסר"** — חודש בלי נתונים מסומן "חסר", לא מוצג כאפס ולא מושלם בניחוש.

---

## התקנה

1. פותחים Claude Code על תיקיית העבודה שלכם — למי שהקים את **המשרד הדיגיטלי**
   (`My Workspace`), זו התיקייה הזאת.
2. מדביקים את הלינק לריפו וכותבים: **"תתקין לי את הסקיל שנמצא כאן בפרויקט הנוכחי"**.
3. מוודאים שיש חיבור לגיליונות — בקומפוזיו (Connected Labs → Google Sheets → Connect),
   כמו בשיעור החיבורים של המועדון. הסקיל קורא מהגיליון בלבד.

### עובד בתוך המשרד הדיגיטלי

מי שעובד במבנה של המועדון (`context/` · `skills/` · `outputs/`):

- **קורא** את `context/business.md` (הזיכרון העסקי) ואת `context/pricing.md` ממדריך
  התמחור — העלויות הקבועות משם משמשות בדיקת שפיות מול הגיליון.
- **שומר** את `dashboard-config.md` ב-`context/`.
- **בונה** את `דשבורד-רווחיות.html` לתוך `outputs/`.
- מפתחות וטוקנים — רק ב-`.env`. קישור לגיליון אפשר בקונפיג.

## שימוש

```
# פעם אחת — חיבור למקורות
"תקים לי את דשבורד הרווחיות"

# כל חודש, אחרי שסקיל הקבלות סיים
"תעדכן את הדשבורד"
```

בהקמה הסקיל שואל: איפה גיליון ההוצאות, איך תרצו להזין הכנסות (לשונית חודשית —
מספר אחד לחודש), ומאשר איתכם מיפוי ספקים לקטגוריות.

---

## מה הסקיל לא עושה

- **לא נוגע בגיליון הקבלות.** קריאה בלבד — לא משנה, לא מוחק.
- **לא מחטט בהכנסות שלכם במייל.** מספר הכנסות אחד לחודש, מכם. אמין ובטוח יותר.
- **לא ממלא חורים.** אין נתונים לחודש — הוא מסומן "חסר". גרף עם חור עדיף על גרף שמשקר.
- **לא דוח מס.** דשבורד תפעולי לקבלת החלטות; הדיווח נשאר אצל הרו״ח.
- **לא שולח נתונים לשום מקום.** הדשבורד קובץ מקומי על המחשב שלכם.
